# Klassischer Hefezopf

Verwendet wird das freie Wikibooks-Rezept für einen ungefähr 1000 g schweren Hefezopf. Der angepasste Rezepttext steht unter CC BY-SA 4.0 und darf kommerziell genutzt und bearbeitet werden; erforderlich sind Namensnennung, Quellen- und Lizenzlink, Änderungshinweis und Weitergabe der Bearbeitung unter gleicher Lizenz.

Das getrennt geprüfte Foto von Monika Baechler zeigt echte Schweizer Butterzöpfe und wurde bei Pixabay unter CC0 veröffentlicht; die Freigabe wurde auf Wikimedia Commons bestätigt. CC0 erlaubt kommerzielle Nutzung und Bearbeitung ohne Namensnennungspflicht. RESERVE nennt die Urheberin trotzdem. Weil die genaue Rezeptur der abgebildeten Zöpfe nicht belegt ist, wird das Foto ausdrücklich als Serviervorschlag gekennzeichnet.
