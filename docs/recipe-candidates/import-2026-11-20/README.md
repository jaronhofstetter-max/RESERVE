# Steirische Kürbiscremesuppe

Verwendet wird das freie Wikibooks-Rezept für eine traditionelle steirische Kürbiscremesuppe. Die Quelle nennt keine Portionenzahl; aus dem rund 3,9 kg schweren Gesamtansatz werden transparent acht Hauptmahlzeit-Portionen abgeleitet. Stückgewichte sowie die in der Zubereitung erwähnten, aber in der Zutatenliste nicht bezifferten Mengen für Fett, Essig und Gewürze sind offengelegt. Der angepasste Rezepttext steht unter CC BY-SA 4.0.
