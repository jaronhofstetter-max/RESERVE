# Zimtsterne und Papet vaudois

Das angepasste Wikibooks-Rezept für Zimtsterne wird unter CC BY-SA 4.0 weitergegeben. Das Foto von 4028mdk09 bleibt getrennt unter CC BY-SA 3.0 Unported. Quellen, Urheber, Lizenzlinks und Änderungen stehen im Rezept beziehungsweise in der Fotoliste. Das bestehende RESERVE-Rezept für Papet wurde um ein Foto von Popo le Chien unter CC0 1.0 ergänzt. Beide Fotos sind Serviervorschläge.

Die Zutaten werden auf vier Backportionen skaliert. Referenzwerte pro 100 g stehen in `nutrition-values.json`. Für jede Zutat wird der Referenzwert mit Gramm je Backportion / 100 multipliziert; von den USDA-Gesamtkohlenhydraten werden die Ballaststoffe abgezogen. Rum: 1,25 ml je Backportion × 0,40 × 0,789 g/ml × 7 kcal/g; kein Verdunstungsverlust angesetzt. Summen werden auf zwei Dezimalstellen gerundet. Angaben sind Schätzungen.

Die Fotos wurden anhand der Originaldateien geprüft. Die Dateiquellen und SHA-256-Prüfsummen der Originale stehen in `source.json` und im Fotomanifest.
