# Vanillekipferl

Rezept: Wikibooks-Mitwirkende (erfasst von Oliver Merkel), Version 1077279. Foto: Flominator, «Flos Vanillekipferl», eigenes Werk von 2007. Für beide wird CC BY-SA 4.0 genutzt: Namensnennung, Quellen- und Lizenzlink, Änderungshinweis und Weitergabe der jeweiligen Bearbeitung unter gleicher Lizenz.

Das Foto wird als Serviervorschlag markiert. Die exakte Nusswahl ist nicht nachgewiesen. Zutaten, Schritte, Allergene und Schätzung sind lokal hinterlegt. Vier Backportionen bilden den grossen Ansatz ab; keine normale Dessertportion. Mengenannahmen und Zuckerüberschuss sind ausdrücklich erläutert.

Nährwerte: aus den dokumentierten Referenzwerten und Grammgewichten nachrechenbar; verfügbare Kohlenhydrate ohne Ballaststoffe. Referenzwerte aus bestehenden Belegen wiederverwendet; keine neue USDA-Abfrage behauptet.
