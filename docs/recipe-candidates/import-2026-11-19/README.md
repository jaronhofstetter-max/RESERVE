# Knoblauchsuppe mit Rahm

Verwendet wird das freie Wikibooks-Rezept für vier Personen. Beim Bereich von 8–10 Knoblauchzehen wird gemäss RESERVE-Regel die niedrigere Zahl verwendet. Nicht gewichtete Löffel- und Stückangaben sowie die Wahl der Gemüsebouillon werden transparent dokumentiert. Der angepasste Rezepttext steht unter CC BY-SA 4.0.

Das getrennt geprüfte Originalfoto von Christian Michelides zeigt echte Knoblauchsuppe und steht unter CC BY-SA 4.0; zusätzlich liegt eine bestätigte Wikimedia-VRT-Freigabe vor. Text und Foto erlauben kommerzielle Nutzung und Bearbeitung. Erforderlich sind Namensnennung, Quellen- und Lizenzlink, Änderungshinweis sowie Weitergabe der jeweiligen Bearbeitung unter derselben Lizenz.
