Datenschutz

Stand: 9. September 2026

Was RESERVE speichert

Die Web-App speichert Angaben wie Vorrat, Einkaufsliste, Profil und Einstellungen grundsätzlich lokal im Browser des verwendeten Geräts (Local Storage). Diese Daten dienen dazu, die Funktionen der App bereitzustellen.

Keine Benutzerkonten

In der aktuellen Version gibt es keine RESERVE-Benutzerkonten und keine eigene zentrale Datenbank, in die dein persönlicher Vorrat oder dein Profil hochgeladen wird.

Technische Bereitstellung

RESERVE wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können technisch notwendige Verbindungsdaten beim Hosting-Anbieter anfallen. Für die Verarbeitung durch GitHub gelten die dortigen Datenschutzbestimmungen.

Externe Dienste

Einzelne Funktionen können externe Dienste verwenden, zum Beispiel Produktinformationen beim Barcode-Scan oder technische Bibliotheken. Dabei kann dein Gerät Verbindungen zu diesen Anbietern herstellen. RESERVE verkauft keine persönlichen Nutzerdaten.

Daten auf deinem Gerät löschen

Die lokal gespeicherten RESERVE-Daten können über die Website-/Browserdaten für diese Website gelöscht werden. Danach startet RESERVE auf diesem Gerät wieder ohne den zuvor gespeicherten Vorrat und die Einstellungen.

Kontakt

Fragen zum Datenschutz können über die auf der Anbieterseite genannten Kontaktdaten gestellt werden.

Hinweis: Diese Seite beschreibt die aktuelle technische Version von RESERVE. Werden später Konten, Analysewerkzeuge oder weitere externe Dienste eingeführt, muss diese Information entsprechend aktualisiert werden.
